# Dormitory Management System

Жатақхана бөлмелерін басқаруға және студенттердің орналасу өтінімдерін өңдеуге арналған ақпараттық жүйе. Студенттерге өтінімді онлайн беруге, ал комендантқа бөлмелерді есепке алуға көмектеседі.

## Мақсаты
Жатақхана бөлмелеріне орналасу процесін автоматтандыру және қағазбастылықты азайту.

## Пайдаланушылар
- Студент
- Комендант
- Әкімші

## Талаптар
1. Студент жүйеге тіркеліп, жеке кабинетіне кіреді.
2. Студент бос бөлмелердің тізімін қарайды.
3. Студент таңдаған бөлмеге орналасуға өтінім береді.
4. Комендант келіп түскен өтінімдерді қарап, бекітеді немесе қабылдамайды.
5. Жүйе бөлмелердің күйін (бос / бос емес) автоматты түрде жаңартады.
6. Студент өз өтінімінің мәртебесін көреді.
7. Әкімші пайдаланушыларды және бөлмелер тізімін басқарады.
8. Жүйе өтінім нәтижесі туралы студентке хабарлама жібереді.
